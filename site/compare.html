How Hunch compares

Four kinds of tools touch engineering memory for AI-assisted code. Each is good at something. Hunch is the only column below that both records the why and enforces it without a model.

Compared by category, on purpose: tools within a category differ, and all of them ship faster than any table. Where a property varies inside a category, we say so. Categories: August 2026 snapshot. Hunch column: v1.52.0, November 2026.

01

It remembers the why

Decisions, the alternatives you rejected and the bugs behind them, linked to the code they explain.

02

It checks with code

No model call in the block path. Every block cites the rule, decision or incident behind it.

03

It stays yours

Committed JSON in .hunch/. No account, no cloud dependency. Teams sync through their own Git remote.

“varies” means credible tools in the category land on both sides of the property. Every Hunch claim is testable against the public source: the source of truth is committed JSON, the gates are deterministic code, and blocks print their citations.

Pick the right tool

You may not need Hunch if…

You work solo in one editor and just want it to remember preferences. Its built-in memory is enough.

Or your rules are purely import-shaped. An import-contract linter is a solid, deterministic answer.

Hunch is built for…

Teams of people and agents where decisions, finished work, commitments and the why behind code must outlive a session, whichever assistant did the work.

The one-line difference

An event → curated rationale → human-scoped authority → deterministic change receipt.

Hunch also ships a self-hosted shared-state service. Its broader cross-agent impact is still being measured.
